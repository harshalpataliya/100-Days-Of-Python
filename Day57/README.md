# Day 57 - Flask URL Building and Jinja Templating

## What I Learned

Today I continued learning Flask and learned how to build dynamic web pages using URL building and Jinja templating.

The main topics I learned were:

- URL Building in Flask
- Jinja Templating
- Using Jinja inside HTML
- Passing data from Flask to HTML
- Dynamic HTML pages
- Flask Routes
- Template rendering

## Project

### Blog Website

For today's project, I built a Blog Website using Flask and Jinja templating.

The project uses Flask for the backend and HTML templates with Jinja to create dynamic pages.

## What I Practiced

Through this project, I practiced how Flask can pass data to HTML templates and how Jinja can be used to display dynamic content.

I also learned how `url_for()` can be used to build URLs for different Flask routes instead of manually writing URLs.

## Project Result

The final project is a simple Blog Website created using Flask, HTML, CSS, and Jinja templating.

The website contains dynamic pages that are connected through Flask routes.

## Key Learning

Day 58 helped me understand how Flask and Jinja work together to create dynamic web applications.

I learned that Flask handles the backend logic and routing, while Jinja allows Python data to be dynamically displayed inside HTML templates.
