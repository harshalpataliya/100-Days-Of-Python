# Day 64 – Movie Listing Website

Today I continued learning about databases and web development with Flask, SQLite, and SQLAlchemy.

For today's project, I built a Movie Listing Website where movies can be added and displayed on the website.

## What I Learned

- Working with Flask and databases
- SQLite database
- SQLAlchemy ORM
- Creating database models
- Adding records to a database
- Retrieving data from a database
- Displaying database records on a webpage
- Updating movie information
- Deleting records from the database
- Working with Flask routes
- Using HTML templates with Flask
- Connecting a web application with a database

## Project

The project is a Movie Listing Website.

The website allows users to add movies and display the movies stored in the database.

Each movie can contain information such as:

- Movie title
- Year
- Description
- Rating
- Ranking
- Review
- Image

The movie information is stored in a SQLite database using SQLAlchemy.

## Technologies Used

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Jinja2

## Main Concepts

### Flask

Used Flask to create the web application and handle different routes.

### SQLite

Used SQLite to store the movie information in a database.

### SQLAlchemy

Used SQLAlchemy to interact with the SQLite database using Python models instead of writing raw SQL for every operation.

### CRUD Operations

The project helped me understand the basic CRUD operations:

- Create – Add a movie
- Read – Display movies
- Update – Modify movie information
- Delete – Remove a movie

## What I Learned From This Project

This project helped me understand how a real web application can use a database to store and manage information.

I also learned how Flask, SQLAlchemy, and SQLite can work together to create a dynamic website.
