# Day 36 - Stock Trading News Alert

## About

Today I learned how to work with APIs and use them to get real-world data.

For the project, I created a Stock Trading News Alert program. The program checks the stock price and gets related news articles. If there is a significant change in the stock price, it can find recent news and send an alert.

## What I Learned

* How to work with APIs
* How to make API requests using Python
* How to use API endpoints
* How to work with JSON data
* How to extract specific information from an API response
* How to use environment variables for sensitive information
* How to work with stock market data
* How to get news data from an API
* How to use Python to automate notifications

## Project

The project uses stock market information and news data to create a stock alert system.

The basic flow is:

```text
Stock API
    ↓
Check Stock Price
    ↓
Significant Price Change
    ↓
News API
    ↓
Get Recent News
    ↓
Send Notification
```

## Technologies Used

* Python
* APIs
* JSON
* Requests
* Stock Market API
* News API

## What I Practiced

This project helped me understand how different APIs can be connected together in one Python program. I also learned how Python can be used to collect real-world information and automate tasks based on that information.
