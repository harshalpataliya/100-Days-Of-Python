## Project

### Higher Lower Game

For today's project, I built a Higher Lower game using Flask and Python decorators.

The project uses Flask to create a web application where the user interacts with the game through a browser.

## Concepts Used

- Python

- `render_template()`

## How It Works

The Flask application creates different routes for the game.

The user enters a number through the URL, and the application compares the entered number with the randomly generated target number.

Based on the result, Flask renders the appropriate HTML response.
