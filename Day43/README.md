# CSS

## What is CSS?

**CSS** stands for **Cascading Style Sheets**.

CSS is used to style and control the appearance of HTML elements.

While HTML is used to create the structure of a webpage, CSS is used to control how that webpage looks.

CSS can be used to change:

- Colors
- Fonts
- Text size
- Backgrounds
- Spacing
- Borders
- Layout
- Overall appearance
