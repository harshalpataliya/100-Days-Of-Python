# Day 66 – Cafe Website

Today I learned about HTTP methods and how they are used to handle requests in web applications. I applied these concepts by building a Cafe Website using Flask.

## What I Learned

- HTTP methods and their purposes
- GET requests to retrieve data
- POST requests to submit data
- PUT requests to update existing data
- PATCH requests to partially update data
- DELETE requests to remove data
- Flask routes and HTTP methods
- Handling form submissions in Flask
- Building web applications with Flask

## Project Description

The Cafe Website is a small web application built using Flask. It helped me understand how HTTP methods work and how a web application can handle different types of requests.

## HTTP Methods

- **GET:** Retrieves information from the server.
- **POST:** Sends data to the server to create or submit information.
- **PUT:** Replaces or updates an existing resource.
- **PATCH:** Updates specific parts of an existing resource.
- **DELETE:** Removes a resource.

## Technologies Used

- Python

- HTTP Methods
