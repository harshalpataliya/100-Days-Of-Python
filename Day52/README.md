#  Instagram Follower Bot

A Python automation project that uses Selenium to automate interactions with Instagram through a web browser.

This project was created as part of Day 52 of Angela Yu's 100 Days of Python course.

##  About the Project

The Instagram Follower Bot is a browser automation project built using Python and Selenium.

The program automates actions on Instagram by controlling a web browser and interacting with different web elements.

This project demonstrates how Python can be used for browser automation and web interaction.

##  Features

- Opens Instagram automatically
- Automates browser interactions
- Logs into an Instagram account
- Finds web elements on the page
- Uses Selenium for browser automation
- Performs automated actions
- Handles dynamic web elements

##  Technologies Used

- Python
- Selenium
- Google Chrome
