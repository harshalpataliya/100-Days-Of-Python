# Day 46 – Time Machine Project: Spotify

##  About

In this project, I built a **Time Machine Project** that allows the user to enter a date from the past and creates a **Spotify playlist containing the Billboard Hot 100 songs from that date**.

This project combines:

- Web Scraping
- HTTP Requests
- Beautiful Soup
- Spotify API
- Authentication
- Exception Handling
- Working with external APIs

---

##  Project Goal

The goal of this project is to:

1. Ask the user for a date.
2. Scrape the Billboard Hot 100 chart for that date.
3. Extract the song titles.
4. Search for those songs on Spotify.
5. Create a Spotify playlist.
6. Add the songs to the newly created playlist.

### Example

If the user enters:

```text
2000-01-01

- The program finds the Billboard Hot 100 songs from January 1, 2000 and creates a Spotify playlist containing those songs.
