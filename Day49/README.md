#  Day 49 – Automating Workout Routine with Selenium

##  About the Project

This project was completed as part of my **100 Days of Python** journey.

The goal of this project is to automate a workout routine using **Selenium WebDriver**. The program interacts with a website automatically and performs actions that would normally be done manually in a web browser.

This project helped me understand how **browser automation and web interaction** work using Python.

---

##  Features

-  Opens and controls a web browser automatically
-  Interacts with website elements
-  Automates workout-related actions
-  Simulates user input
-  Locates elements on a webpage
-  Performs repetitive browser tasks automatically

---

##  Technologies Used

- Python 
- Selenium
- Chrome WebDriver

---

## Concepts Practiced

During this project, I practiced:

- Browser Automation
- Selenium WebDriver
- Locating Web Elements
- XPath
- CSS Selectors
- Automating Click Actions
- Sending Keyboard Input
- Working with Web Pages
- Python Automation

---

## How It Works

The program follows these steps:

1. Launches the web browser using Selenium.
2. Opens the required website.
3. Locates the necessary web elements.
4. Performs automated actions such as clicking buttons and entering information.
5. Completes the required workout automation process.
