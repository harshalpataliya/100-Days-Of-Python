# Day 63 – SQLite & SQLAlchemy

Today I learned about working with databases in Python. I learned how to use SQLite and SQLAlchemy and used them to store and manage data in a small website.

## What I Learned

- What a database is and why it is used
- SQLite database
- Creating and working with database tables
- Adding data to a database
- Reading data from a database
- Updating and deleting data
- SQLAlchemy
- Using SQLAlchemy with Flask
- Creating database models
- Connecting a Flask website with a database

## Project

For today's project, I created a small website that uses a SQLite database through SQLAlchemy.

The project helped me understand how a website can store and retrieve information from a database instead of keeping everything only in Python variables.

## Technologies Used

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS

## What I Learned From This Project

This project helped me understand the basic connection between a web application and a database. I also learned how SQLAlchemy makes it easier to work with databases using Python objects and models.
