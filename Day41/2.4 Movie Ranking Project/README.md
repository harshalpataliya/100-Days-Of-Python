Day 41 of my **100 Days of Python** journey was focused on learning the fundamentals of the web.

Before starting web development with Python, I learned how the Internet works, how websites work behind the scenes, and the roles of the three main web technologies:

- HTML
- CSS
- JavaScript

##  How the Internet Works

The Internet is a global network that allows computers and other devices to communicate with each other.

When we visit a website, several things happen between our browser and the server hosting that website.

A simplified version of the process is:

User
  ↓
Web Browser
  ↓
Internet
  ↓
Web Server
  ↓
Website Resources
  ↓
Web Browser
  ↓
Web Page
