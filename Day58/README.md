## Project

### Tindog Website

For today's project, I built a Tindog website using HTML, CSS, and Bootstrap.

Tindog is a website design project inspired by a dating platform for dogs.

The main purpose of this project was to practice Bootstrap and learn how to create a responsive website more easily.

Through this project, I practiced how Bootstrap can be used to create responsive layouts without writing all the CSS from scratch.
