#  Tinder Bot

##  About

This project is a **Tinder Bot built with Selenium** that automates interactions on Tinder through a web browser.

It was created as part of **Day 50** of Angela Yu's *100 Days of Code: Python* challenge.

The project helped me practice browser automation, element interaction, keyboard actions, and working with dynamic web pages using Selenium.

---

##  Features

-  Opens Tinder automatically using Selenium
-  Automates the login process
-  Automatically interacts with profiles
-  Automates repetitive Tinder actions
-  Uses Selenium to interact with web elements
-  Uses delays to handle page loading and dynamic content

---

##  Technologies Used

- Python
- Selenium
- WebDriver
- Chrome Browser

---

##  Concepts Learned

- Selenium WebDriver
- Finding elements using Selenium
- Clicking buttons automatically
- Keyboard interaction
- Handling dynamic web pages
- Using `time.sleep()` for synchronization
- Browser automation
- Exception handling

---

##  How It Works

1. The Selenium WebDriver launches Chrome.
2. Tinder is opened in the browser.
3. The bot performs the required login steps.
4. Selenium locates Tinder interface elements.
5. The bot automatically performs the programmed actions.
6. The process continues according to the automation logic.
