# Day 29 - Password Manager

## Overview

Today I built a Password Manager application using Python and Tkinter. In this project, I learned how to create a more advanced GUI and started adding functionality to save user data and generate secure passwords.

## What I Learned

- Creating a GUI using Tkinter
- Using `Canvas` to display images
- Using `PhotoImage` to load a logo
- Working with `Label`, `Entry`, and `Button` widgets
- Organizing widgets using the `grid()` geometry manager
- Using `columnspan` to adjust the layout
- Reading user input with `.get()`
- Writing data to a text file using file handling
- Using append mode (`"a"`) to save data without overwriting existing content
- Creating functions for different tasks
- Generating random passwords using:
  - `random.choice()`
  - `random.shuffle()`
- Converting a list of characters into a password string
- Understanding how to connect GUI widgets with Python functions using the `command` parameter

## Features

- User-friendly Password Manager GUI
- Website input field
- Email/Username input field
- Password input field
- Generate Password button
- Add button to save credentials
- Saves credentials to `data.txt`

## Concepts Practiced

- Tkinter GUI Development
- Functions
- File Handling
- Lists
- Loops
- String Manipulation
- Random Module
- Event Handling

## What I Found Challenging

- Designing the GUI layout using `grid()`
- Adjusting widget sizes and alignment
- Understanding `columnspan`
- Connecting buttons with their functions
- Saving user input into a text file
- Integrating the password generator into the GUI

This project helped me understand how different Python concepts such as Tkinter, functions, file handling, and the random module work together to create a real desktop application. It also improved my confidence in building GUI applications and debugging layout issues.
