#  Data Entry Job Automation

A Python automation project that searches for rental property listings and automatically enters the collected data into an online form.


##  About the Project

The Data Entry Job Automation project combines **web scraping** and **browser automation**.

The program collects property information such as:

- Property address
- Rental price
- Property listing link

It then automatically enters the collected information into an online form.

This project demonstrates how Python can automate repetitive data collection and data entry tasks.

##  Features

-  Scrapes property listing information from a website
-  Collects property addresses
-  Collects rental prices
-  Collects property links
-  Automatically opens a web browser
-  Automatically fills out an online form
-  Repeats the process for multiple property listings
-  Automates repetitive data entry tasks

##  Technologies Used

- Python
- BeautifulSoup
- Requests
- Selenium
- Google Chrome
