# Day 57 - Flask Static Files and HTML/CSS

## What I Learned

Today I continued learning Flask and learned how to work with static files in a Flask web application.

The main topics I learned were:

- Rendering static files
- Working with HTML files
- Working with CSS files
- Linking CSS with HTML
- Flask project structure
- Serving static files with Flask
- Connecting Flask with frontend files

## Project

### Personal Identity Card

For today's project, I built a Personal Identity Card using Flask.

The project uses Flask to serve the HTML page and CSS file, creating a simple personal identity card that can be viewed in a web browser.

## Technologies Used

- Python
- Flask
- HTML
- CSS

## Concepts Used

- Flask
- HTML Templates
- Static Files
- CSS Styling
- Flask Routes
- `render_template()`
- Flask Static Folder

## What I Practiced

Through this project, I practiced how to organize HTML and CSS files in a Flask project and how Flask can render HTML pages while serving CSS as a static file.

I also learned how frontend files can be connected to a Python Flask backend.

## Project Result

The final project is a simple Personal Identity Card webpage created using Flask, HTML, and CSS.

## Key Learning

Day 57 helped me understand how Flask applications can work with frontend files such as HTML and CSS.

This is an important step toward building complete web applications using Python and Flask.
