# What is Selenium?

**Selenium** is a Python library that allows us to automate web browsers.

Unlike normal web scraping, where we only download and read the HTML of a webpage, Selenium can actually control a browser.

With Selenium, Python can perform actions such as:

- Open a website
- Click buttons
- Enter text
- Find elements
- Read information from a webpage
- Navigate between pages
- Interact with dynamic content

      ↓
Selenium
