# Day 37 - Habit Tracker

## About

Today I learned how to work with different HTTP methods and API authentication.

For today's project, I built a **Habit Tracker** using an API. The project allows me to create, update, and delete habit-tracking data through API requests.

- HTTP PUT requests
- HTTP DELETE requests
- Request headers
- API authentication
- How to send authentication information using request headers
- How to work with API endpoints
- How to send data to an API
- How to update existing data using an API
- How to delete data using an API
- How to work with APIs using Python
