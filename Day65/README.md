# Day 65 – Web Design Basics

Today I learned about the fundamentals of web design and how to create visually appealing and user-friendly websites.

## What I Learned

- Color palettes and color combinations
- Typography and font selection
- User Interface (UI) design
- User Experience (UX) design
- Website layout and visual hierarchy
- Choosing suitable colors and fonts for websites
- Designing websites that are attractive and easy to use
- Importance of consistency in web design

### Color Palettes
Learned how to choose and combine colors to create a consistent visual appearance for a website.

### Typography
Learned about selecting appropriate fonts, font sizes, and text styles to improve readability.

### User Interface (UI) Design
Learned how to design the visual elements of a website, including buttons, layouts, colors, and navigation.

### User Experience (UX) Design
Learned how to make websites easier to navigate and more convenient for users.

## What I Learned From This Day

This lesson helped me understand that web development is not only about writing code. Good website design also requires thoughtful color choices, readable typography, a clear interface, and a positive user experience.
