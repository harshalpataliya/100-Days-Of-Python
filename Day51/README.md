#  Twitter Complaining Bot

##  About

This project is a **Twitter Complaining Bot built with Selenium** that automatically checks Twitter/X for a specific internet speed issue and posts a complaint when the actual speed is lower than the promised speed.

The project helped me practice web automation, working with dynamic websites, reading information from web pages, and automatically posting content using Selenium.

---

##  Features

-  Opens a browser automatically using Selenium
-  Checks the current internet download speed
-  Checks the current upload speed
-  Compares the actual speed with the promised speed
-  Automatically opens Twitter/X
-  Creates a complaint tweet
-  Automatically posts the complaint
-  Automates repetitive browser interactions

##  How It Works

1. The Selenium WebDriver launches Chrome.
2. The bot opens the internet speed testing website.
3. It starts the speed test.
4. The bot collects the download and upload speeds.
5. The actual speeds are compared with the expected speeds.
6. If the internet speed is lower than expected, the bot opens Twitter/X.
7. The bot writes a complaint message.
8. The complaint is automatically posted.
