## Project: U.S. States Game

In this project, I built an interactive **U.S. States Guessing Game** using **Python**, **Turtle Graphics**, and **Pandas**.

### Features
- Displays a blank map of the United States.
- Accepts user input for state names.
- Uses a CSV file to retrieve state names and their coordinates.
- Displays correctly guessed states on the map.
- Keeps track of guessed states.
- Continues until the player exits the game.
